# Module: mod_mpu6050

MPU-6050 accelerometer and gyroscope. Broadcasts raw acceleration data on a regular interval and emits a shake event when a sudden movement exceeds the configured threshold.

## Enable

```cpp
#define ENABLE_MPU6050
```

---

## Config defines

| Define | Default | Description |
|--------|---------|-------------|
| `MPU_SDA_PIN` | `LCD_SDA_PIN` | I2C data. Defaults to LCD SDA if defined — they share the same I2C bus. |
| `MPU_SCL_PIN` | `LCD_SCL_PIN` | I2C clock. Same note. |

`Wire.begin()` must be called once in `accessory_node.ino` before `mpu_setup()`. The MPU-6050 default I2C address is `0x68` (AD0 to GND) or `0x69` (AD0 to 3V3).

---

## CAN frames

### Sends

| ID | Name | Payload | Rate |
|----|------|---------|------|
| `0x302` | `IMU_DATA` | `[accel_x_lo, accel_x_hi, accel_y_lo, accel_y_hi, accel_z_lo, accel_z_hi]` | Periodic (configured in firmware) |
| `0x303` | `SHAKE_EVENT` | `[magnitude, axis_mask]` | On shake detection only |

`IMU_DATA` payload: each axis is a little-endian int16, raw ADC units from the MPU-6050 (±2g default full-scale → divide by 16384 for g).

`SHAKE_EVENT` payload:
- `data[0]` = magnitude (0–255, scaled)
- `data[1]` = axis mask: bit 0 = X axis exceeded threshold, bit 1 = Y, bit 2 = Z

### Receives

None.

---

## Integration notes

- `mpu_loop()` must be called every `loop()`.
- If both `ENABLE_LCD` and `ENABLE_MPU6050` are defined, the MPU and LCD share the same I2C bus. This is fine — `Wire` handles multiplexing. Both pins must be identical (`MPU_SDA_PIN == LCD_SDA_PIN`).
- The MPU-6050 has a built-in interrupt pin. The current firmware polls it rather than using the interrupt — `mpu_loop()` frequency determines sample rate.
- Shake detection threshold is configured in `mod_mpu6050.cpp`. Typical use is to trigger the Viper alarm (`TRIG_ANY(0x303)` → `ACT_VIPER(0x01)`) via a rule on any node that receives the frame.
